# snRNA-seq and spatial-transcriptomics analyses — Figures 1 & 2

Single-nucleus RNA-seq and spatial-transcriptomics analysis code accompanying
the manuscript on the **ADGRG1–RhoA–type III collagen axis in astrocyte scar
formation after spinal cord injury**.

The notebooks were originally developed on Google Colab and have been adapted
to run on either Google Colab or a local Jupyter environment.

---

## 1. Repository contents

| File              | Figure   | Contents |
|-------------------|----------|----------|
| `Fig_1-E.ipynb`   | Fig. 1E  | snRNA-seq QC, integration (Harmony), Leiden clustering, astrocyte subclustering (`Astro-NT_1`–`Astro-NT_6`), PAGA / DPT pseudotime, subcluster composition by timepoint, and CellPhoneDB ligand–receptor analysis at 0d / 1d / 4d / 7d / 14d / 1m. |
| `Fig_2A.ipynb`    | Fig. 2A  | Circos plot of collagen-mediated ligand–receptor interactions at 7 d post-injury, with the COL3A1–ADGRG1 pair highlighted (`pycirclize`). |
| `Fig_2B-C.ipynb`  | Fig. 2B–C | Bubble plot of COL3A1–ADGRG1 interactions (VLMC / ABC → Astro-NT) at 7 d (`ktplotspy`), and timecourse of interaction scores across 0d–1m. |
| `Fig_2D.ipynb`    | Fig. 2D  | 3D spatial-transcriptomics visualization of Col3a1 / Adgrg1 / Gfap co-expression, with k-nearest-neighbor analysis. |
| `requirements.txt`| —        | Python dependencies. |
| `README.md`       | —        | This file. |

## 4. Setup

### Option A — Google Colab

Open any notebook in Colab. The first cell auto-detects Colab, mounts Google
Drive, and sets `BASE_DIR = '/content/drive/MyDrive/scRNA_analysis'`. Edit this
path in the first cell if your Drive layout differs. Then install dependencies
once per session:

```python
!pip install -r requirements.txt
```

### Option B — Local Jupyter

```bash
# Python 3.10 or 3.11 recommended
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# Tell the notebooks where the data lives
export SCRNA_BASE_DIR=/path/to/scRNA_analysis    # Windows: set SCRNA_BASE_DIR=...

jupyter notebook
```

If `SCRNA_BASE_DIR` is unset, the notebooks fall back to `./data`.

## 5. Recommended run order

1. **`Fig_1-E.ipynb`** — generates `filtered_data_Ver2.h5ad`, `Results_0-1m/*.h5ad`,
   and the `figures_Ver2/statistical_analysis_*.txt` files used by figure-2 notebooks.
2. **`Fig_2A.ipynb`** — reads `figures_Ver2/statistical_analysis_interaction_scores_timecourse_7d.txt`.
3. **`Fig_2B-C.ipynb`** — reads `Results_0-1m/Meta_Mix_CPDB_7d_selected.h5ad`,
   `Meta_Mix_0-1m.h5ad`, and the `statistical_analysis_*` files at multiple
   timepoints.
4. **`Fig_2D.ipynb`** — reads the `GSE234774_spatial_3d_*` files directly.

Each notebook is designed to run top-to-bottom on a machine with at least
**32 GB RAM** (64 GB recommended for the full integrated dataset). The
CellPhoneDB sections in `Fig_1-E.ipynb` are the most memory- and
compute-intensive; they were originally run with 5 threads and 1000 permutation
iterations.

## 6. Software environment

The original analyses were run on Google Colab (Python 3.10/3.11) in May 2025.
The notebooks themselves are platform-agnostic; the first cell handles the
Colab-vs-local branching. If you want a frozen environment, run
`pip freeze > frozen_requirements.txt` after your first successful run and use
that file thereafter.
